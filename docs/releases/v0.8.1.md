Primeira versão pública do **PlastfortSul CRM** — atendimento no WhatsApp Business, clientes, funis, campanhas e automações.

## Inclui

- App Next.js 16 (atendimento, clientes, Kanban, campanhas, automações, fluxos, IA, relatórios, papéis de equipe)
- Schema Supabase até a migração **044** (campos comerciais, playbooks, ocorrências, motivo de perda, respostas rápidas)
- Docker multi-estágio (`standalone`) e Compose
- Opt-out de WhatsApp (inbound + envio de automação)
- API REST (`/api/v1`) e servidor MCP
- CI (lint, typecheck, testes, build) e verificação de migrações em PR

## Como usar este release

O zip **Source code** desta página é o código. Não há instalador `.exe` nem pacote npm.

1. Extraia (ou `git clone` + `git checkout v0.8.1`)
2. Siga [docs/deploy.md](../deploy.md) no servidor ou na Vercel
3. Variáveis: [docs/configuracao-env.md](../configuracao-env.md)
4. Aplique as migrações em `supabase/migrations/` no projeto Supabase **antes** de abrir o app em produção

## Requisitos

- Node.js 20 ou superior
- Projeto Supabase (Postgres + Auth)
- App Meta (WhatsApp Cloud API) para o canal de fato funcionar
